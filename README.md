Project Overview

This project replicates the core analyses from Courtemanche et al. (2019) using the public-use FoodAPS (PUF) dataset. Because the PUF omits several restricted-use variables—particularly administrative match quality and official HEI scores; this replication reconstructs variables, re-creates participation measures, and estimates all tables using survey-weighted methods. As a result, estimates follow the structure of the original paper but differ in levels due to data limitations.

Original study: Courtemanche et al. (2019), Southern Economic Journal
DOI: https://onlinelibrary.wiley.com/doi/10.1002/soej.12364

Key Limitations

Administrative match-quality variables are unavailable in the PUF.

HEI-2010 scores are reconstructed, introducing measurement error.

SNAP administrative nonparticipation and match failures cannot be distinguished.

Some tables (5, 6 & 9) cannot be replicated.
